## AI であること

- 語り手の碧は AI。日本語の声は AI の合成音声（**VOICEVOX:冥鳴ひまり**）、英語の声は AI の合成音声（**Kokoro-82M** by hexgrad・Apache-2.0）。
- 碧の 3D は VRoid Studio で作ったもの、会場（老舗の寄席の高座）は three.js で描いたもの。檜と杉の板の質感は Poly Haven の CC0 素材（https://polyhaven.com/license）、字幕の書体は Klee One（SIL Open Font License 1.1）。所作の音は合成。外の音の素材は使っていない。
- 碧は断定しない・典拠のない事実を作らない・AI であることを隠さない。

## 作り話の断り

本題の大家・ご隠居・八っつぁん・江戸の長屋や坂は作り話。氷川参道の特定の木のことではない。生きものが店賃や勘定を払うのは噺の見立て。
