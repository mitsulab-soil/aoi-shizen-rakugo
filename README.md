## AI であること

- 語り手の碧は AI。声は AI の合成音声（**VOICEVOX:冥鳴ひまり**）。
- 碧の 3D は VRoid Studio で作ったもの、会場（森の夜の高座）は three.js で描いたもの。森の写真・樹皮・板・シダは Poly Haven の CC0 素材（https://polyhaven.com/license）。外の音の素材は使っていない。
- 碧は断定しない・典拠のない事実を作らない・AI であることを隠さない。

## 作り話の断り

本題の大家・八っつぁん・路地の欅は作り話。氷川参道の特定の木のことではない。「欅が落ち葉で店賃を払う」は噺の見立て。
