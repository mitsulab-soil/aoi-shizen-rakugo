# Qualia/rakugo ／ mitsulab

蜂の目、ミミズのからだ、蛾の触角、蜘蛛の網、犬の鼻、欅の葉、写真機の目、星の光。ほかのものが受けとっている世界を、碧（あおい）が噺に訳して語る落語。聞いたあと、いつもの世界の見え方が変わる。mitsulab が「Qualia Layer」（ほかの主体の受けとり方を、人の感覚へ写した一枚）と呼ぶものの、「語り」の層。

公開先：https://mitsulab-soil.github.io/aoi-shizen-rakugo/
